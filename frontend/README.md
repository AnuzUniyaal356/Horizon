YouTube Clone 🎥
A full-stack YouTube clone built with modern web technologies, featuring video streaming, channel management, and AI-powered features.


✨ Live Demo
Frontend: https://your-youtube-frontend.onrender.com
Backend API: https://your-youtube-backend.onrender.com

🚀 Features
🎬 Video Management
Upload Videos - Support for multiple formats with progress indicators

Video Streaming - Adaptive streaming with quality options

Video Player - Custom player with controls and fullscreen support

Thumbnail Generation - Automatic thumbnail creation

Video Analytics - View counts and engagement metrics

👤 User Experience
User Authentication - Secure login/signup with Firebase Auth

Channel Creation - Personalize your own channel

Subscribe System - Subscribe to favorite channels

Watch History - Track your viewing history

Playlists - Create and manage video playlists

Likes & Comments - Engage with content

🤖 AI-Powered Features
Smart Recommendations - AI-powered suggestions using Gemini AI

Automated Tagging - AI-generated tags and categories

Content Moderation - AI-assisted content filtering

Transcript Generation - Automatic closed captions

🛠️ Tech Stack
Frontend
React 18 - Modern React with hooks

Context API - State management

React Router - Client-side routing

Axios - HTTP client

CSS3 - Responsive design

Firebase SDK - Authentication

Backend
Node.js & Express.js - Server framework

MongoDB & Mongoose - Database and ODM

JWT - Authentication tokens

Cloud Services
Cloudinary - Video and image storage

Firebase Auth - User authentication

Google Gemini AI - AI features

Render - Deployment platform

📦 Installation
Prerequisites
Node.js (v16 or higher)

MongoDB Atlas account

Cloudinary account

Firebase project

Google Gemini AI API key
